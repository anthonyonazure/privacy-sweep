# Changelog

## Unreleased

### Added

- Extra report-only audits, run at the end of each OS audit and also runnable alone: `audit/audit-extra-windows.ps1` (Windows Recall folder and policy, PowerShell history and logging, USB and device history beyond USBSTOR, Explorer TypedPaths / WordWheelQuery / RunMRU / dialog MRUs, Remote Desktop history and bitmap cache, Bluetooth pairings, Timeline and notification databases, RegBack, installed-software keys), `audit/audit-extra-macos.sh` (Messages database size, Bluetooth, AirDrop and Screen Time settings files, Siri and Apple Intelligence folders, `.zsh_sessions` and other tool history, install history), and `audit/audit-extra-linux.sh` (package-manager logs, Flatpak and Snap data, USB connect-event counts, Bluetooth, saved Wi-Fi, keyrings, GeoClue, Remmina and FreeRDP). All three also report SSH `known_hosts` line counts and cloud CLI and Docker folders. They print presence, sizes, and counts only, never message text, host names, device serials, commands, or credentials. Windows Recall paths follow Microsoft's public documentation and should be verified on your build. On macOS, Messages and some Library folders report "protected" instead of "not present" when the terminal lacks Full Disk Access.
- Opt-in modules that stay out of `clear-all`: `recovery-purge/` (VSS, APFS local snapshots, Document Revisions; dry-run unless `--apply`, plus a typed phrase), `browser-deep/` (LevelDB, IndexedDB, session restore, Crashpad; bookmarks kept; refuses a running browser), `memory-residue/` (pagefile, hiberfil, sleepimage, swap), and `local-artifacts/` (screenshots, clipboard managers, Office MRU, chat caches, notification DBs, `.DS_Store`, DNS flush, auditd vacuum). Mail stores are audited and never deleted.
- Report-only modules: `cloud-sync/` (local sync cache presence, with a per-service checklist that clearing local does not clear the account) and `persistence/` (login items, scheduled tasks, Run keys, user units, cron presence). Nothing is unloaded or deleted.
- `docs/reduce-future-logging.md` and `docs/anti-forensics.md`. The first lists telemetry and index switches this repo does not flip. The second describes wipe-tool names, timestamp comparisons, and why timestomp, decoys, USBSTOR deletion, keychain extraction, and journal mutilation are out of scope.
- `./privacy-sweep.sh --dry-run --all-modules` and `.\privacy-sweep.ps1 -DryRun -AllModules` dry-run every module, including the opt-in ones, and pass no apply flag. `-AllModules` forces a dry run. The Windows launcher sets `$LASTEXITCODE`. An SSD free-space refusal (exit 2) is reported and does not fail that dry run.
- Android usage-stats presence (`android/audit-usage.sh`) and a Digital Wellbeing package section in `android-tv/audit-tv.sh`. Both are report-only. `ios/README.md` states that desktop FOSS cannot replace a mobile acquisition.
- Windows audit fixes from a real dry run: Wi-Fi profile names are parsed only after `-match` succeeds, the recovery report prints once per process, USBSTOR says its subkeys are ACL'd to `NT AUTHORITY\SYSTEM`, and a missing HKCU Explorer hive notes that an SSH or service logon can differ from an interactive session.

### Fixed

- `clear-local.sh` counts and deletes `.DS_Store` with the same time limit and prune list as the audit. `~/Library`, CloudStorage, `node_modules`, and `.git` are not walked.
- The other-profile note still lists OneDrive for Business and SharePoint roots on another profile when this session does not have those roots, even if this session has a consumer OneDrive folder. The note gives names and counts only. A `-ProfilePath` run does not recommend that same profile again.
- Windows cloud-sync no longer assigns `$HOME`, which Windows PowerShell treats as a read-only automatic variable. The PowerShell parse check rejects assignments to automatic names (`$home`, `$profile`, `$pid`, `$host`, `$input`, and the other read-only names). `$null =` stays allowed.
- If this session's profile has no browser or OneDrive data and another profile under `Users` does, the report names that profile and the counts only. `-ProfilePath` audits another profile. A clear of that profile still requires `-Apply` and the usual confirmation.
- The home-wide `.DS_Store` scan uses the same time limit as the other home scans, and that limit stops the `find` process, not only its parent. `~/Library` is pruned along with CloudStorage, Mobile Documents, Containers, Group Containers, `node_modules`, and `.git`. A LaunchAgent file name that contains a control character is reported with the character escaped.
- macOS cloud and home scans no longer walk File Provider or iCloud Drive trees. Those roots are a top-level count with no `du`. Home-wide finds prune CloudStorage, Mobile Documents, Containers, Group Containers, `node_modules`, and `.git`, and each large scan stops after `PRIVACY_SWEEP_SCAN_TIMEOUT` seconds (default 20) instead of hanging. Desktop, Documents, and Downloads are probed with a timed `ls` before they are scanned.
- A Safari bookmarks file this session cannot read is reported as present and unreadable, without an "Operation not permitted" error. A running browser is named in the refusal.
- The macOS recovery report prints once per `--all-modules` run. A sleepimage plan with `hibernatemode` other than 0 says it would not remove the file. Launch agents are listed once per file name, and macOS 13+ login items try `sfltool dumpbtm` without sudo.
- Windows browser profiles are found from `LOCALAPPDATA` / `APPDATA` or `USERPROFILE\AppData`, including Firefox `profiles.ini`, and a missing browser is reported as not installed. `-AllModules` passes the event-log and search-index plans (channel sizes and the rebuild plan). OneDrive for Business, SharePoint sync roots, and OneDrive log folders are top-level counts. The VSS purge preview is a count, creation dates, and storage used.
- `find | wc` counts in the macOS and Linux clear and audit scripts no longer abort a dry run when `find` hits an unreadable directory.

- `audit/`: report-only recovery structures, from the same per-OS audit scripts that already report execution stores, knowledgeC, Biome, FSEvents, and Linux login-record sizes. Windows shadow-copy counts, Recycle Bin `$I`/`$R` counts, pagefile/hiberfil/MEMORY.DMP presence and size, search-index size, thumbcache database counts, BitLocker protection status. macOS local snapshots, Document Revisions size, external `.Trashes` counts, sleepimage/swap presence, FileVault on/off. Linux swap, LUKS status without keys, and a shallow scan for wipe-tool remnant names. Nothing is deleted, and file contents are not printed.
- `docs/leave-no-trace.md`: the five layers (log less, clear named stores, purge recovery structures, hard-disk free space, encryption and key destruction), why free-space fill on an SSD is not a wipe, the cipher/SDelete/`z` fingerprint names, and why not to plant decoy history entries.
- `hdd-free-space/`: opt-in free-space fill for a hard disk (`cipher /w` on Windows, a fill file on Linux). Dry run first, asks unless `--yes`, refuses SSDs unless `--i-know-this-is-ssd`. Not part of `clear-all`. Does not purge snapshots. macOS is a pointer to the advisory, not a wipe. Snapshot and shadow-copy purge is the separate `recovery-purge/` module, also not part of `clear-all`.
- `network/pihole-tv/`: brand-selectable HaGeZi lists (`--brand samsung,lg,roku,firetv`), a keep-list that is allowlisted and never added as a block, and AdGuard Home (`--adguard`) beside Pi-hole for list adds and the ACR client report. Vizio and Hisense stay on the combined lists. The README's first steps are the on-TV ACR settings and a guest network.
- `android-tv/audit-tv.sh`: report-only package list over network `adb`. Flags known telemetry, ad, and content-row packages. Disables nothing, and is not part of `clear-all`.
- `network/pihole-tv/`: add maintained smart-TV and ACR blocklists to a Pi-hole you administer, and report which LAN clients queried those names. List changes are a dry run unless you pass `--ask` or `--yes`. Pi-hole v6 is the HTTP API; v5 can be updated through a local `gravity.db`.
- `network/pihole-report/`: weekly markdown DNS report (top clients, top blocked domains, new clients, ACR hits), plus example cron and systemd timer files.
- `network/router-hygiene/`: checklist for the router admin page, and `check-lan.sh` for the checks a LAN host can actually make.
- `network/device-inventory/`: ARP inventory, with mDNS, SSDP, and `nmap -sn` after you confirm. Flags unnamed devices and TVs on this LAN.
- `audit/`: per-OS report of counts and paths (Prefetch, Jump Lists, USBSTOR, recent items, Wi-Fi profiles, quarantine, Quick Look, thumbnails, shell history). Also reports Windows execution stores that can outlive a deleted program (ShimCache/AppCompatCache, Amcache.hve, SRUM, BAM/DAM, UserAssist, ShellBags), macOS unified logs, knowledgeC, Biome, and FSEvents, and Linux screenshot folders, journal size, `wtmp`/`lastlog`/`btmp` size, and user crontab presence. `recently-used.xbel` was already counted. Nothing is deleted.
- `browsers/`: history, cookies, and cache for Chrome, Edge, Firefox, Safari, and Brave. Refuses a browser that is still open. Not part of `clear-all`.
- `android/audit-permissions.sh`: adb report of accessibility, device admin, SMS, call log, notification listeners, and overlay, plus non-Play installs. Removes nothing.
- `forget-wifi` scripts for Windows (`netsh`), macOS (`networksetup`), and Linux (`nmcli`). The network you are using is kept unless you pass `--include-current`.
