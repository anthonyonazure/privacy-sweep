privacy-sweep — macOS

What your Mac remembers ▍

Every file you opened, every photo you deleted, the link for every download, every Wi-Fi password. Here's where each lives and how to clear it by hand.

github.com/anthonyonazure/privacy-sweep — scripts that do it for you
01Deleted-photo previews
A cached thumbnail can outlive the photo you deleted.
qlmanage -r cache
Then Photos › Recently Deleted › Delete All.
02Browser, the full clear
Safari › Settings › Privacy › Manage Website Data › Remove All. History, cookies, and cache in one pass.
03Saved Wi-Fi passwords
Passwords app › Wi-Fi. Touch ID reveals every stored network password. Forget one in System Settings › Wi-Fi.
04Clipboard history
macOS 26 keeps one: Spotlight, then Cmd+4. Turn it off in System Settings › Spotlight.
05Recent files
Apple menu › Recent Items › Clear Menu. Stop it: System Settings › Desktop & Dock › Recent documents › None.
06The download log nobody mentions
macOS records every download and its source URL. Clearing browser history doesn't touch it.
sqlite3 ~/Library/Preferences/com.apple.LaunchServices.QuarantineEventsV2 'delete from LSQuarantineEvent'
07Terminal command history
: > ~/.zsh_history # then: history -c
★The real fix

Turn on FileVault (System Settings › Privacy & Security). It encrypts the whole disk, so every store above is unreadable when the Mac is off or locked. One switch covers all of them.

Scope: personal privacy hygiene on your own device. Not a list of everywhere a forensic examiner looks, and not a way to defeat an investigation.
